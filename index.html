Casa Cannith
01

POSITION

Permite posicionar elementos de forma precisa en relación al flujo normal del documento y a otros elementos.

Es ideal para superponer capas, crear efectos visuales y ubicar elementos en lugares específicos.

Propiedades clave

  • position
  • top
  • right
  • bottom
  • left
  • z-index

02

FLEXBOX

Diseñado para distribuir elementos en una dimensión (fila o columna).

Permite alinear, justificar y distribuir elementos de manera eficiente incluso si cambian de tamaño.

Propiedades clave

  • display:flex
  • flex-direction
  • justify-content
  • align-items
  • gap
  • flex-wrap

GRID

Diseñado para organizar elementos en filas y columnas.

Ideal para construir interfaces complejas donde varias secciones necesitan alinearse simultáneamente.

Propiedades clave

  • display:grid
  • grid-template-columns
  • grid-template-rows
  • gap
  • justify-items
  • align-items
